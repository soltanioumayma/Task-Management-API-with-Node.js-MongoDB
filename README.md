# TP Node.js

This project is a simple Node.js application developed using **Express.js**.

## Description

The project demonstrates the basics of creating a REST API with Node.js and Express, including:

* Creating an Express server
* Defining routes
* Handling HTTP requests and responses
* Using route parameters, query parameters, and request bodies
* Working with JSON data

## Technologies

* Node.js
* Express.js
* JavaScript

## Run the project

Install the dependencies:

```bash
npm install
```

Start the server:

```bash
node server.js
```
